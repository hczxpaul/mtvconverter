## 「歪了」= button 的 UA text-align: center 继承进 flex 子项

主人圈出「导入」与「歌词与字幕」两个标题不在一条竖线上。根因不是 flex 居中，而是 `<button>` 浏览器默认 `text-align: center` 被子元素继承：`.lyrics__toggle` 是 flex + space-between，第一个 span 内含「标题」+ `<small>` 摘要两行，span 宽度由较长的摘要决定，于是标题在 span 内部被居中、第二行越长偏移越大。

修法：`.lyrics__toggle`、`.lyrics__sub-toggle` 显式 `text-align: left`。

**判别特征**：箭头位置正常（说明 flex 生效），但第一行文字不贴左且偏移量随第二行长度变化 —— 遇到这种就查 button 的 text-align，不要改 justify-content。

验证方式：把 `.card__head` 与 `.lyrics__toggle` 两段 DOM 拼进一个独立 HTML，用 build 出的真实 CSS 渲染对比，一次就能复现。

## 歌词列宽改为「按最长句实测 + 三重约束」

主人反馈歌词列太宽（一句歌词通常不长），要求按最长句定宽、保留最小值、可设最大值、多的给预览。

**实现**：新增 `hooks/useLyricsColumnWidth.ts` —— canvas `measureText` 量 `lines` 里最长一句（按 version 取 primary / bilingual 取更宽行），加行内固定开销 `ROW_CHROME = 156`（打点22+删除22+间距4+padding12+gap10+时间码52+border2+卡片padding22+滚动条余量8），clamp 到 250–360。

**三道约束**：
1. hook 上限 360（超了换行，不为个别长句撑宽）
2. CSS 再夹：`min(var(--lyrics-w), max(250px, 100% - 290px - 320px - 20px))` —— 预览最小 320 优先
3. 设置列 `minmax(290px, 360px)`，剩余全给预览

**实测（grid 容器宽度 → 设置/歌词/预览）**：1440→360/337/695；1280→360/337/535；1160→360/337/415；1066→360/337/321（刚好守住 320）。

**注意**：`FONT` 常量与 `ROW_CHROME` 跟 CSS 强耦合，改歌词字号必须同步。

## 歌词列入场动效

- 列宽 0 → 目标宽，220ms ease-out cubic（rAF 补间）；卡片 `lyricsColIn`（淡入 + translateX 10px，delay 40ms）；首屏前 10 行 `lyricsRowIn` 错峰 12ms。
- **关键坑**：补间值必须放 state，不能直接 `style.setProperty` —— 列宽变化触发 ResizeObserver → 重渲染 → React 的 style prop 把变量打回终值，动画只跑一帧。

## 歌词列退场动效（四态机）

`hidden / entering / visible / leaving`。入场 220ms ease-out，退场 180ms ease-in（`(1-t)^2`，先慢后快收得干脆），都 rAF 补间列宽；卡片 `lyricsColOut` 淡出 + translateX 8px，`pointer-events: none`。

关键点：
- 离场**先播完再卸载**：`wantLyricsCol=false` 只推到 `leaving`，补间到 0 才置 `hidden`。
- 离场期间 `lyricsColWidth` 已经是 0（歌词空了），必须用 `lastColWidthRef` 记住收起前宽度，否则从 0 收到 0、动画不可见。

## 图标按钮被旧 padding 压成「·」（2026-11-16 修）

症状：歌词列表行首打点图标变成一个小点，行尾 × 消失。

根因：`.lyrics__lines button { padding: 4px 9px; display: flex }`（0,1,1）压过 `.timeline__pin`（0,1,0）。22px 按钮减左右各 9px → 内容区 4px，14px SVG 被 flex 压成 4px 宽竖缝。

修法：选择器提到 `.lyrics__lines li > .timeline__pin`（0,2,1），显式 `padding:0 / gap:0 / flex:0 0 22px`，svg 写死 14px（删除 13px）。

**排查手段**：`getBoundingClientRect()` 量 svg 宽高（得到 [4,14]）+ `getComputedStyle(pin).display`（得到 flex 而非 grid）——两个值就能定位到覆盖来源。
