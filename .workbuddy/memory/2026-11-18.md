## 修的 5 个 Windows 缺陷
1. `escapeFilterPath()`：`-vf` 值被解析两次，Windows 盘符冒号必须写 `\\:`（单层 `\:` 直接 AVFilterGraph 解析失败，字幕烧录必失败）。
2. 硬件自检样本 `128x128` 低于 NVENC HEVC 最小帧尺寸 → 每台 N 卡机器误判「硬件编码器不可用」并降级 CPU。改 256×256。
3. NVENC 把 x265 CRF 直接当 `-cq` → 138% 源体积。实测 cq=crf+5（84% ≈ x265 crf28 的 85%，VMAF 94.7 vs 93.0），并加 `-rc vbr -b:v 0 -preset p5 -tune hq`。
4. `tests/jobs.test.ts` 写死 POSIX 路径 → Windows 7 项假失败，改 `path.join`。
5. `ConfigService.executableOnPath()` 用 `which`（Windows 没有）→ 改 `where`。
